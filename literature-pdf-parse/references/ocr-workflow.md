# 扫描版 PDF 与 OCR（提得全 · 扫描件）

目标：对**无文字层**的扫描论文、低分辨率页做可复核的文字识别，并对 OCR 错字做后处理校验。

## 1. 先判定是否有文字层（避免白跑 OCR）

1. 用 `pdf-text-tool` 抽取若干页，统计每页可见字符数。
2. 若绝大多数页字符数接近 0 → 扫描件，走 OCR。
3. 若仅个别页为空（插图页、照片页）→ 只对这些页 OCR，其余页走电子版流程。
4. 混合文档（部分页有文字层、部分扫描）→ 逐页判定，逐页处理，记录哪些页走了 OCR。

## 2. 渲染（栅格化）

1. 用 `pdf-render-tool` 或 `pdftoppm -r 300 -png` 渲染为 PNG；分辨率至少 300 DPI，字号小或版面密可到 400–600 DPI。
2. 大页面按栏/区块切分后分别渲染，避免整页缩放导致小字糊掉。

## 3. 预处理（按需，不要过度处理）

1. **灰度化**：彩色扫描转灰度。
2. **二值化**：自适应阈值（如 Otsu），保留字符边界，去背景噪点。
3. **去倾斜（deskew）**：用投影法或直线检测估计倾斜角并校正。
4. **放大**：小字号区域放大 1.5–2× 再识别。
5. 预处理只改善可读性，**不得改变版面结构**（栏、行、单元格位置保持）。

## 4. OCR 识别

1. 用 `ocr-tool`，语言提示 `chi_sim+eng`（中英混排科研文献）；纯英文文档用 `eng`。
2. 若工具返回**每字/每行置信度**与坐标，保留下来用于后处理与定位。
3. 分页/分块识别，避免超长页导致漏识别。

## 5. 后处理校验（OCR 不能直接当真相）

1. **逐项比对**：OCR 结果与渲染图并排核对，重点查：
   - 数字（0/O、1/l/I、5/S、6/G、8/B）；
   - 单位（µ vs μ、°C、Å、µm）；
   - 公式符号（下标 vs 正文、希腊字母、±、×）；
   - 中文形近字、生僻字、人名/机构名。
2. **低置信度标注**：置信度低于阈值的字符/词标 `low_confidence`，保留渲染图定位，不硬猜。
3. **正则校验**：数字串、DOI、邮箱、页码等按模式检查；明显不符的标 `uncertainty`。
4. **上下文纠错**：仅在低置信度处依据相邻高置信度文本做最小纠正，并记入 `change_log`（如 "0.92 中 '0' 原 OCR 为 'O'，据渲染图更正"）；无把握就保留原样 + 标注。

## 6. 输出与溯源

- OCR 结果按页/区块回填到正文流，每条带 `locator`（页码 + 区块）与 `source: "ocr"`。
- 低置信项汇总到 `result.json` 的 `uncertainty`。
- 保留渲染图路径作为证据（`/app/output/pages/page_N.png`），便于人工复核。

## 7. 校验

- 抽查 1–2 页：OCR 文本与渲染图逐字比对；漏识别（整块空白）要重渲染/重识别。
- 公式、表格、脚注是否被 OCR 当成正文串行——表格仍需走表格重建，公式仍需走符号转录，不直接吃 OCR 平铺文本。
