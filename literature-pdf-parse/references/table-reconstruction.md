# 复杂表格解析（拆得清 · 表格）

目标：把表格还原为**行、列、单元格归属正确**的结构，含合并单元格、多层表头、跨页续表。输出 Markdown / HTML / 结构化 JSON，数值不转录错误。

## 1. 输入与判定

1. 优先使用带**框线坐标**的提取：`pdf-text-tool` 若提供矢量线（水平线、垂直线）坐标，用它重建网格最可靠。
2. 无框线时用**文本对齐投影**：把单元格文本按 `x0` 聚成列、按 `y0` 聚成行。
3. 判定"这是不是表格"：同一行内多个文本块在垂直方向对齐、且多行重复出现 → 表格；否则是普通正文，不要硬套网格。

## 2. 网格重建

### 2.1 有框线
1. 收集所有水平线 y 坐标与垂直线 x 坐标。
2. 对 y 坐标聚类（容差 2–3 pt）得到**行边界**；对 x 坐标聚类得到**列边界**。
3. 相邻行边界之间、相邻列边界之间的矩形即**单元格**；落在某单元格内的文本块归属该单元格。

### 2.2 无框线（文本对齐）
1. 取所有单元格的 `x0` 做一维聚类得到列起点；`y` 聚类得到行起点。
2. 单元格归属：文本块按最近列起点 + 最近行起点归位。
3. 空单元格（该行列无文本）保留为空，**不得删除**——行列结构必须完整。

## 3. 合并单元格（rowspan / colspan）

1. 单元格跨越多个列边界且含一段连续文本 → `colspan=N`；跨越多个行边界 → `rowspan=N`。
2. Markdown 无法原生表达跨行时，用显式标注，例如 HTML `<td rowspan="2">`，或结构化 JSON 的 `{"value": "...", "rowspan": 2, "colspan": 1}`。
3. 合并单元格内的文本只归属一次，不要在下个单元格重复。

## 4. 多层表头

1. 表头可能有多层（大类列 + 子列）。按行边界判断表头占几行，保留层级结构。
2. 输出时用表头层级（JSON 的嵌套字段或 Markdown 的分组）表达，不把多层表头压成一层。

## 5. 跨页续表

1. 下一页开头出现与上一页表格**列头相同/相近**的重复表头 → 判定为续表。
2. 续表合并为一张表，重复表头只保留一次，`change_log` 记录"第N页与第N+1页为同一表格的续表，已合并"。
3. 跨页拆分的行若被页面截断，按单元格内容续接，不得丢行。

## 6. 图片型表格（无文字层/无框线）

1. 用 `pdf-render-tool`（或 `pdftoppm -r 300`）渲染表格区域为高分辨率图。
2. 用 `ocr-tool` 识别，语言提示 `chi_sim+eng`。
3. OCR 后按文本对齐投影重建网格；识别置信度低的单元格标 `low_confidence`，保留原图定位，不硬猜数值。

## 7. 输出格式与校验

- 结构 JSON 至少含：`{table_id, page, rows: [{cells: [{value, rowspan, colspan, low_confidence}]}]}`。
- Markdown 用 `| ... |` 管道表（简单表）或 HTML（含合并单元格）；表头与数据行分隔线正确。
- 校验：
  - 行数 × 列数与版面一致；无空列/空行被误删。
  - 合并单元格不重复计数；跨页续表行数 = 两页行数之和（去重复表头）。
  - 抽查 2–3 个单元格数值与渲染图逐字一致（尤其小数、单位、正负号）。
