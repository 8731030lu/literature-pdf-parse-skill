# 公式与特殊字符转录（拆得清 · 符号保真）

目标：把公式按**结构元素**还原为可继续处理的形式，保留上下标、希腊字母、特殊符号。不要求理解公式含义。

## 1. 转录原则

1. **一致性**：同一文档内统一用 LaTeX（推荐，`$...$` 内联、`$$...$$` 独立）或统一用 Unicode；不要混用导致歧义。
2. **保留结构**：上标 `^`、下标 `_`、分式 `\frac{a}{b}`、根号 `\sqrt{n}`、求和 `\sum`、积分 `\int`、希腊字母、向量/矩阵记号都要还原，不压成平铺字符。
3. **不重排、不改值**：公式是"结构元素"转录，不是重写；原始符号、顺序、编号不得改动。
4. **保留编号**：`(1)`、`(2a)`、`Eq. 3` 等公式编号与公式一起输出，并附定位。

## 2. 上下标

- 判定：字号明显小于基线文本、且 y 偏移高于（上标）或低于（下标）基线的字符 → 上/下标。
- LaTeX：`E_i`、`x^2`、`E_{ij}`（多字符下标用花括号）。
- Unicode（如作为纯文本输出时）：`Eᵢ`、`x²`、`Eᵢⱼ`；无法用 Unicode 表达就保留 LaTeX。

## 3. 希腊字母与特殊符号映射（常见）

| 常见 | LaTeX | Unicode |
|---|---|---|
| α β γ δ ε | `\alpha \beta \gamma \delta \varepsilon` | α β γ δ ε |
| θ λ μ π σ φ ω | `\theta \lambda \mu \pi \sigma \phi \omega` | θ λ μ π σ φ ω |
| Γ Δ Σ Ω | `\Gamma \Delta \Sigma \Omega` | Γ Δ Σ Ω |
| ∂ ∇ ∫ ∑ ∏ | `\partial \nabla \int \sum \prod` | ∂ ∇ ∫ ∑ ∏ |
| √ ± × · → ↔ ≤ ≥ ≠ ∞ | `\sqrt \pm \times \cdot \to \leftrightarrow \le \ge \ne \infty` | √ ± × · → ↔ ≤ ≥ ≠ ∞ |

- 工具返回的字符若已正确，**直接采用**，不要二次"翻译"导致失真。
- 符号不确定时（如 `v` vs 希腊 `ν`），对照渲染图确认；仍不确定则标 `low_confidence` 并保留原文，不硬猜。

## 4. 公式识别边界

1. 公式常以独立行出现、居中或带编号；内联公式夹杂在句子中（`$...$`）。
2. 独立公式：整块转录为一条 `formula` 记录 `{id, page, locator, latex, number, low_confidence}`。
3. 内联公式：在正文句子中保留其 LaTeX/Unicode 原位，不断开句子。
4. 多行推导（对齐的等号、分步）：逐行转录，保留换行与对齐，标记为 `derivation` 结构。

## 5. 校验

- 抽查 2–3 个公式与渲染图逐符号比对（上下标位置、希腊字母、运算符）。
- 特殊符号编码后仍可读：`\frac`、`\sum` 等不被截断或丢参数。
- 编号与上下文一致；无公式时如实标 `formulas: []` 或 `not_reported`，不造公式。
