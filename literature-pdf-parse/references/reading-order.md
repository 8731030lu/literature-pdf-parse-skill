# 多栏阅读顺序与文字提取（排得对）

本文给出**可执行**的多栏阅读顺序重建算法。输入是带坐标的文本块，输出是原版面顺序的文本流。目标是"不串栏、不错行、不把相邻段落拼成一句"。

## 1. 输入块格式

统一用以下 JSON 数组表示每个文本块（一行或一段一个对象）：

```json
[
  {"page": 1, "x0": 72.0, "y0": 100.5, "x1": 245.0, "y1": 112.3, "text": "first line", "font": "Times-Roman", "size": 10.0}
]
```

- 坐标单位为 pt（1 pt = 1/72 inch）；`y0` 为块顶，`y1` 为块底（PDF 坐标系原点通常在左下，`y` 越大越靠上）。
- `x0/x1` 为水平左右边界，`y0/y1` 为垂直上下边界。
- 若工具返回行级坐标，以行为最小块；若返回词级，可先按行归并。

## 2. 判定栏数与栏边界（每页独立，再做跨页一致性）

0. **先剔除全宽块**：宽度超过页宽 60% 的块（页眉、页码横线、跨栏大图/大表）不参与分栏判定。
   若让一个整行宽块进入区间合并，它会把左右两栏连成一段，沟槽消失、整页退化成单栏——这是双栏论文最常见的误判来源。
1. 取该页**栏宽级**块的水平区间，在一维 x 轴上做**投影直方图**（步长取页面宽度的 1/100 即可）。
2. 找出**贯穿页高 60% 以上**的垂直空白带（覆盖区间无任何文本）：这些就是栏间沟槽（gutter）。
3. 沟槽数量 + 1 = 栏数；沟槽中点把页面切成若干栏区间 `[col_x0, col_x1]`。
4. 若同一 PDF 各页栏数不一致（如首页单栏、正文双栏），**按页分别处理**，并记录哪些页是单栏/双栏。
5. 无法稳定判定时（栏间无空白、文本跨越栏界），保守按单栏处理并在 `uncertainty` 标注。
6. 自检：双栏页若输出中左右栏句子交替出现（L1→R1→L2），说明分栏失败，回到第 0 条检查全宽块是否被误纳入。

## 3. 单栏页排序

对栏内块：先按 `y` 降序（自上而下，PDF 坐标 y 越大越靠上），同一行内（`y` 差 < 0.5×行高）再按 `x0` 升序（左→右）。

## 4. 双栏/多栏页排序

1. 按块 `x0` 归属到最近的栏区间。
2. **每栏内部**按单栏规则排序（自上而下）。
3. **栏间顺序**：按栏从左到右拼接，即"左栏全部 → 右栏全部"；三栏同理。
4. 跨越栏界的大图/大表（宽度超过单栏宽）：单独作为 `spanning` 块，插入到两栏在 y 上对应的位置，不要拆进某一栏。
5. 图注紧跟其图：图注块若与其图同属一栏或紧邻，保持相邻输出。

## 5. 页眉页脚与页码分离

1. 定义顶边距带（`y > page_height - margin`）与底边距带（`y < margin`），margin 默认取页高的 8%，按实际版面调。
2. 落在边距带内、且文本**跨页重复出现**（≥2 页相同或仅数字不同）的块 → `header`/`footer`，从正文流剔除，但**保留证据**（写入 evidence，不静默丢弃）。
3. 页码：纯数字或 `第N页`/`N / M` 形式、位于边距带内 → `page_number`，独立字段记录。
4. 边注（marginal note）：落在栏外窄边距且非页眉页脚 → 单独归类 `margin_note`，附到邻近正文但不混排。

## 6. 跨页续接

1. 上一页末块若**以非句末标点结尾**（无句号/分号，或含未闭合括号、连字符），且下一页首块**不以大写字母/编号开头**，判定为跨页续段。
2. 合并两段时去掉跨页产生的连字符断字（英文 `analy-sis` → `analysis`），并在 `change_log` 记录"第N页末与第N+1页首合并为一段"。
3. 不确定是否续接时**保守不合并**，保留原文并在 `uncertainty` 标注，不要凭语义猜。

## 7. 确定性脚本

`scripts/reading_order.py` 实现上述第 2–6 步的确定性重排（输入块 JSON，输出带 `column`、`kind`、`near_margin`、`order` 的块序列）。用法见脚本头注释与 `examples/demo.md`。

- `kind ∈ {body, header, footer, page_number, spanning, no_coord}`；**页眉/页脚只在跨页重复时判定**，`near_margin` 仅记录"位于边距带"，不得据它直接删正文。
- `--y-origin top|bottom`：按提取器坐标系选择，默认 top（`y0` 为上边）。
- `--page-height`：给出真实页高（pt）时用它算边距带；缺省用文本包围盒，稀疏页会偏窄。
- 相邻小间隙（< 页宽 1.5%）不切栏，避免把同栏内较宽的词间距误判成新栏。

脚本只做几何排序，不做语义判断；语义类判定（如跨页续接的语义确认）由 Agent 依据本文件第 6 条处理。

## 8. 校验方法

- 随机抽 2–3 页，把重排后的正文与该页渲染图并排比对：栏首、栏尾、图注位置、段落边界是否一致。
- 检查是否有"相邻段落被拼成一句"：输出流中两个块之间若原属不同栏却无换行/段落分隔，即为错误。
- 检查页眉页脚是否已剔除：全文检索页眉短语，应只出现在证据区而非正文流。
